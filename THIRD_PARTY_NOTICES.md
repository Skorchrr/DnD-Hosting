## Party Ledger interoperability

The Shadowkeep bridge was written against the Party Ledger data structures supplied by the project owner. It imports Party Ledger JSON content packs and maps classes, subclasses, species, backgrounds, feats, spells, items, monsters, and feature records into Shadowkeep's catalog.

This package does not include Party Ledger's application runtime, Firebase project configuration, API credentials, or visual assets. It is not affiliated with Party Ledger, Wizards of the Coast, or Aurora Builder.
